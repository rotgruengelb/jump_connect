# How to use
Hold The `Alt`/`Ctrl`/`Shift` down and click the Multiplayer Button in the Main Menu.
The Mod then connects you to the Server Address you have configured for `Alt`/`Ctrl`/`Shift`.

# How to Config
Use Mod Menu to access the Configuration Screen of the Mod :)
