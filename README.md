# How to use
Hold The `Alt`/`Ctrl`/`Shift` down and click the Multiplayer Button in the Main Menu.
The Mod then connects you to the Server Address you have configured for `Alt`/`Ctrl`/`Shift`.

## How to Config
Use Mod Menu to access the Configuration Screen of the Mod :)](https://github.com/rotgruengelb/jump_connect)

## Dependencies
- [FabricAPI](https://modrinth.com/mod/fabric-api)
- [owo-lib](https://modrinth.com/mod/owo-lib)
- [Nixienaut](https://modrinth.com/mod/Nixienaut)

& You should install [Mod Menu](https://modrinth.com/mod/modmenu) to get access to the config Screen.
